# Navegación a la pagina principal

La aplicación `fauna scan` provee una interfaz amigable para la clasificación de imágenes de fauna utilizando modelos de deep learning.

El dashboard de la aplicación se ve en la siguiente imagen:

![Dashboard](dashboard.png)

Al darle click en seleccionar imagen, se abre un explorador de archivos para seleccionar la imagen a clasificar, como se muestra a continuación:

![Chose image.png](chose-image.png)

Una vez elegida la imagen, se da click en el botón de clasificar imagen y se obtiene el resultado de la clasificación, como se muestra a continuación:

![clasify](clasify-image.png)

Al dar click en el botón de clasificar, se puede visualizar el resultado como se muestra a continuación:

![Classified animal](classified-animal.png)

Al terminar la clasificación, el sistema queda disponible para ejecutar una nueva clasificación.
